# output

Results of runs that took their files from `input\` (or ran with `--out` pointing here):

- `<drawing>_FromDWG.pln`: the site model.
- `<drawing>_FromDWG_report.html`: what was found and done, and what to check.

Runs given files on the command line write to an `output` folder where the command is run.

Only this README is kept in git; everything else in this folder stays on your computer.
