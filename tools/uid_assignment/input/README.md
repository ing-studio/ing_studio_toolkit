# input

The tool works on the project **open in Archicad**, so in normal use nothing goes here.

Keep test projects here, to try the tool from a terminal on a copy:

```
uid.bat --output --project input\Hasratyan_plans.pln --out output
```

(The project must be open in Archicad for the plain `uid.bat`; `--output` opens its own helper Archicad.)

Only this README is kept in git; everything else in this folder stays on your computer.
