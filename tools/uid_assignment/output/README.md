# output

The tool writes next to the project it works on: `output\` beside the `.pln`. This folder holds the results of the test projects in `input\` (`--out output`):

- `<project>_window_ids.pln` / `.pdf`: the project with the window IDs, its plans with the ID labels;
- `<project>_window_types.pln` / `.pdf`: the window types worksheet.

Only this README is kept in git; everything else in this folder stays on your computer.
