# input

Put the files of one run here, then double-click `relief.bat` (or run it without file names):

- the point cloud(s): E57, LAS, LAZ, PLY, PCD, PTS, PTX, XYZ, TXT, CSV, ASC. Several are merged into one relief.
- optionally the Archicad project (`.pln`) the relief must line up with.

Files given on the command line (`relief.bat survey.e57`) are used instead, wherever they are.

Only this README is kept in git; everything else in this folder stays on your computer.
